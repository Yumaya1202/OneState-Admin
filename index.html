管理者向けの対応手順・処罰方法・記録方法

1. Admin Levelごとの処罰権限について

■ 基本原則

管理者は、自分に割り当てられたAdmin Levelで許可されている範囲内の処罰のみ実行できます。

■ 権限が不足している場合

自分のAdmin Levelでは対応できない処罰が必要な場合は、所定の手順でBAN申請を行ってください。

■ 永久BANについて

Version 1.3以降、Moderatorは永久BANを実行できません。永久BANが必要な場合は、Senior Staffへ申請・相談してください。

■ 注意事項

  • 自分のAdmin Levelで許可されていない処罰は実行しない。
  • 判断に迷った場合は、独断で処罰せずSenior Staffへ確認する。
  • 権限を超える処罰が必要な場合は、所定の申請・報告手順に従う。

重要：自分の権限範囲を守り、適切な手順で処罰を実行してください。

2. 投獄・ミュート処罰について

■ ① Admin Panelを使用した投獄

Admin Panelから違反内容を選択し、処罰を実行します。

  1. 対象プレイヤーを選択する。
  2. 該当する違反コードを選択する。
  3. 理由が正しく設定されていることを確認する。
  4. 設定された処罰時間を確認し、処罰を実行する。

例： RP1（Deathmatch）の場合、理由に「RP1」が設定されていることを確認してから処罰を実行します。

■ ② Freecamを使用した投獄

Freecamを使用する場合は、投獄時間と理由を手動で設定できます。複数の違反コードを適用する場合も、理由が正確に伝わるように記載してください。

コマンド形式

/jail <ID> <投獄時間> <理由>

実行例

/jail 12345 20 RP1

上記は、ID「12345」のプレイヤーを20分間、理由「RP1」で投獄する例です。対象ID・時間・理由に誤りがないことを確認してから実行してください。

. ミュート処罰について

■ ① 通常のミュート

通常のミュートは、ボイスチャットを対象とした処罰です。テキストチャットの発言を制限する場合は、チャンネルミュートを使用してください。

■ ② チャンネルミュート（Channel Mute）

チャンネルミュートは、特定のテキストチャットチャンネルでの発言を制限するために使用します。複数のチャンネルを対象にすることもできます。

対象となるチャンネルは以下のとおりです。

  • System
  • World
  • Faction
  • Interns
  • AllFactions
  • Clan
  • Recruitment
  • Trade
  • Sms

処罰を実行する際は、違反内容に応じて必要なチャンネルのみを選択してください。不必要なチャンネルまで制限しないよう注意してください。

■ ③ チャンネルミュートの記録

チャンネルミュートはシステムログに記録されません。

そのため、処罰を実行する前に、以下の情報が確認できる画面のスクリーンショットを撮影し、指定された記録用チャンネルへ提出してください。

  • 対象プレイヤー
  • ミュート対象のチャンネル
  • 処罰理由
  • 処罰時間

記録が残らない処罰だからこそ、証拠の保存と報告を確実に行ってください。

■ 注意事項

  • 処罰対象のプレイヤーIDを必ず確認する。
  • 違反内容に適した理由・処罰時間を設定する。
  • 通常のミュートとチャンネルミュートを混同しない。
  • チャンネルミュートでは、実行前のスクリーンショット撮影と提出を忘れない。
  • 判断に迷った場合は、独断で処罰せずSenior Staffへ確認する。

重要：適切な処罰を実行するとともに、必要な記録を確実に残してください。

4. Gun Ban（武器使用禁止）について

■ ① Gun Banの概要

Gun Banは、指定した時間、対象プレイヤーの武器使用を禁止する処罰です。

Version 1.3以降、Gun BanはAdmin Levelに関係なく、すべての管理者が使用できます。ただし、使用可能であることと、独断で処罰を決定してよいことは別です。必ず違反内容と最新の運用ルールを確認してください。

■ ② Gun Banの使用例

違反内容に応じて、投獄（Jail）またはGun Banを使用します。

違反コード 投獄（Jail）の例 Gun Banの例
RP220分20分
RP1130〜60分60分
CLAN530分30分
CLAN5.190分90分
CLAN5.290分30分

※ 上記は処罰の運用例です。実際の処罰では、最新のルール・チーム方針を優先してください。

■ ③ チーターが疑われる場合の暫定対応

チート使用が疑われるプレイヤーに対して、被害拡大を防ぐため、正式な処罰が決定するまで暫定的にGun Banを適用する場合があります。

設定例

  • 理由：ALERT3
  • 時間：1440（24時間）

ただし、これは暫定的な対応であり、正式なALERT3の処罰を実行したことにはなりません。

暫定対応を行った場合は、証拠を保存し、Senior Staffへ情報を共有してください。また、Gun Banを適用したことだけを理由に、ALERT3の対応を完了扱いにしないでください。

■ ④ 注意事項

  • Gun Banの使用前に、違反内容と適用時間を確認する。
  • 最新のルールおよびチーム方針を優先する。
  • 曖昧な疑いだけを根拠にGun Banを適用しない。
  • チーターが疑われる場合は、証拠を保存し、Senior Staffへ共有する。
  • 暫定対応と正式な処罰を混同しない。
  • 処罰の実施内容を適切に記録する。

重要：Gun Banは適切な状況で使用し、証拠の保存・情報共有・処罰記録を徹底してください。

5. チャット表示・システムログの記録について

■ ① チャットの全文表示について

Version 1.3以降、チャットの文章が長い場合、末尾が「...」と表示されることがあります。

文章の一部しか表示されていない場合は、該当するチャンネルを開いて全文を確認してください。表示されている部分だけで判断せず、発言の内容を正確に把握することが重要です。

■ ② システムログのスクリーンショット

処罰を実行した際は、システムログのスクリーンショットを撮影し、必要な情報がすべて確認できる状態で記録してください。

スクリーンショットには、以下の情報が含まれていることを確認してください。

  • 対象プレイヤー
  • 処罰理由
  • 処罰時間
  • 実行された処罰内容

情報が途中で切れていないか確認し、後から処罰内容を確認できるように保存してください。

■ ③ チャット削除機能について

Admin Level 1には、Trade Chatやその他のチャンネルのチャットを削除する機能があります。

ただし、現在のチーム方針では、Admin Level 1によるチャット削除の使用は禁止されています。

チャットの削除が必要な場合は、自分で操作せず、Moderator以上の管理者またはSenior Staffへ情報を共有し、対応を依頼してください。

■ 注意事項

  • 「...」で省略されたチャットは、該当チャンネルを開いて全文を確認する。
  • 処罰の記録は、対象プレイヤー・理由・時間・処罰内容が確認できる状態で保存する。
  • スクリーンショットの情報が途中で切れていないか確認する。
  • Admin Level 1は、チーム方針に従いチャット削除を行わない。
  • チャット削除が必要な場合は、Moderator以上の管理者またはSenior Staffへ相談する。

重要：チャットの内容を正確に確認し、処罰記録を適切に保存してください。

6. 最後に

■ マニュアルの更新について

このマニュアルは、ゲームのアップデートやチーム方針の変更に伴い、内容が変更される場合があります。

変更があった場合はチーム内で共有されるため、常に最新のマニュアルと運用ルールを確認してください。

■ 判断に迷った場合

対応方法や処罰の判断に迷った場合は、独断で対応せず、Senior Staffへ確認してください。

自分の判断だけで処罰を実行するのではなく、チーム内で情報を共有し、適切な対応を行うことが重要です。

■ 質問・相談について

マニュアルに記載されていない内容や、対応方法が分からない場合は、遠慮せずSenior Staffへ質問してください。

小さな疑問でも、確認することで誤った対応やトラブルを防ぐことにつながります。

重要：最新のルールを確認し、チーム内で連携しながら、責任を持って管理者業務に取り組んでください。
